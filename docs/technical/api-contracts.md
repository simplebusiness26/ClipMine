# API Contracts

The implemented OpenAPI document is generated by FastAPI at `/openapi.json`; interactive documentation is available at `/docs` while the API runs.

Base path: `/api`

Version: private MVP `0.1.0`

JSON naming: `snake_case`

## Conventions

- Project and candidate IDs are server-generated UUID strings.
- Timestamps are UTC ISO 8601.
- Long processing/render work returns HTTP 202 and is observed by polling the project.
- Validation/errors currently use FastAPI's `detail` shape.
- Project responses embed transcript segments and candidates for this private MVP.
- Source/export bytes are served only by project-bound API routes.
- No authentication exists; the API must stay private.

Example error:

```json
{
  "detail": "Project not found"
}
```

## Service endpoints

### `GET /api/health`

Returns startup/runtime readiness:

```json
{
  "status": "ok",
  "persistence": "json",
  "ffmpeg": true,
  "transcription_provider": "faster-whisper"
}
```

### `GET /api/config`

Returns non-secret UI/runtime limits: persistence kind, database state, upload/duration limits, transcription provider, render size and private-MVP auth label.

## Projects

### `GET /api/projects`

Returns all projects newest first. Private-MVP data is not paginated.

### `POST /api/projects`

Uploads and creates a project. Content type: `multipart/form-data`.

| Field | Type | Requirement |
|---|---|---|
| `file` | file | MP4, MOV, M4V or WebM |
| `rights_confirmed` | boolean | Must be true |
| `title` | string | Optional; filename stem fallback |
| `desired_clips` | integer | 1–12; default 5 |
| `min_clip_seconds` | integer | 5–180; default 20 |
| `max_clip_seconds` | integer | 10–240; default 60 and greater than min |
| `language` | string | Default `auto` |

Returns HTTP 202 with the project after the source is stored and analysis is queued.

Important responses:

- 400: rights missing, empty upload or invalid range
- 413: configured upload limit exceeded
- 415: extension not accepted
- 422: form/schema validation failed

### `GET /api/projects/{project_id}`

Returns the current project, transcript and candidates. Use this for polling.

### `POST /api/projects/{project_id}/retry`

Returns HTTP 202 and re-enqueues a failed or ready project from analysis. Other states return 409.

### `GET /api/projects/{project_id}/source`

Streams the stored source with a container-appropriate media type and `Cache-Control: no-store`.

### `DELETE /api/projects/{project_id}`

Cancels matching in-process work, deletes metadata and removes the project directory. Returns HTTP 204. This is synchronous inside the single-instance private MVP.

## Candidates and exports

### `PATCH /api/projects/{project_id}/candidates/{candidate_id}`

Editable JSON fields:

```json
{
  "title": "A complete takeaway",
  "start_seconds": 12.5,
  "end_seconds": 48.0,
  "caption_text": "Corrected caption text."
}
```

The end must follow the start, stay inside the known source and produce at most a four-minute clip. Any edit invalidates an earlier export reference.

### `POST /api/projects/{project_id}/candidates/{candidate_id}/render`

Returns HTTP 202 after changing render state to queued. Repeated calls while queued/rendering return the existing project and do not start duplicate work.

### `GET /api/projects/{project_id}/candidates/{candidate_id}/download`

Returns the ready MP4 as an attachment. It returns 404 until the candidate state and file both show ready.

## Project schema summary

| Field | Meaning |
|---|---|
| `status` | `uploading`, `uploaded`, `processing`, `ready`, `failed`, `deleting` |
| `stage` | Plain-language current activity |
| `progress` | Coarse 0–100 pipeline progress |
| `analysis_mode` | Whisper model tag or `timeline-fallback` |
| `transcript_segments` | Timestamped recognised text |
| `candidates` | Editable suggestions and render state |
| `error_code`, `error_message` | Safe terminal project error |

Candidate render states: `idle`, `queued`, `rendering`, `ready`, `failed`.

Candidate confidence: `high`, `medium`, `experimental`.

## Polling guidance

The current UI polls an active project roughly every 2.5 seconds. Clients should stop high-frequency polling after terminal project state and after a candidate render reaches ready/failed.

## Public-beta contract changes

The public API must add authentication, workspace ownership, pagination, stable structured error codes/correlation IDs, idempotency keys, direct object upload instructions, asynchronous deletion and signed media access. Those changes require a versioned contract rather than silently changing this private-MVP API.
